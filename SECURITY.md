# Security policy

The framework's security boundaries — what each component controls, what
stays the application's responsibility, and how a report is evaluated
against them — are mapped in [THREAT_MODEL.md](THREAT_MODEL.md). Read it
before deciding whether a behavior is a vulnerability.

## Supported versions

Only the latest tagged release receives security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: open
<https://github.com/abubakarsiddik31/golem/security/advisories/new>
("Report a vulnerability"). Include a reproduction and the affected versions
where you can.

Please do not open public issues, pull requests, or discussions for suspected
vulnerabilities — give the report a chance to be triaged and fixed before
disclosure.
